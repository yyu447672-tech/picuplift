    GOOD TO KNOW

    A few clear answers.

    How does HEIC conversion stay private?

    A bundled WebAssembly decoder reads the image locally in a temporary browser worker. PNG encoding also runs locally. No file is sent to a server and no decoder is loaded from a CDN. We use Google Analytics to measure visits and interactions (such as page views, scrolling, and clicks). Images are always processed locally and are never uploaded.

    Do I have to install anything?

    No. Use the website, or download the full folder and open this page in a current desktop Chrome or Edge. The local assets folder contains the decoder; do not remove it.

    Is HEIC to PNG conversion lossless?

    PNG encodes the decoded pixels without additional lossy compression. At 100% dimensions there is no resizing, but HEIC decoding and color/HDR handling can affect appearance. PNG files may be larger than HEIC; the tool shows actual sizes and lets you keep the original.

    Can I convert unlimited photos?

    There is no imposed file-size or count cap. Real capacity depends on your device and browser. Files run one at a time; ZIP generation may need extra memory or smaller batches.

    Are Live Photos, orientation, and HDR preserved?

    The output is a static PNG using the primary image, not a Live Photo or video. HEIC display transforms are handled by the decoder. Camera metadata is not copied. Color, HDR tone, or some unusual HEIC variants may render differently or be unsupported.

    What if one photo fails?

    That row shows an error and the remaining photos continue. Retry the file, use a smaller batch, or try a current desktop browser. The original file is never modified.
