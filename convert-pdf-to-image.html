    GOOD TO KNOW

    A few clear answers.

    Does the PDF leave my device?

    Files stay in your browser and are never uploaded. Bundled local scripts do the work. Google Analytics measures visits and fixed interaction events; file names and file contents are not included in the tool events.

    Can I open the downloaded page by double-clicking it?

    This tool needs an HTTP(S) page because browsers restrict local JavaScript modules and module workers under file://. Use the hosted website or serve the complete folder locally. It loads PDF.js, fonts, maps and decoding components from the same local site, never a CDN.

    Does it support password-protected PDFs?

    No. Select an unprotected copy you are permitted to use. Empty, invalid and password-protected files show an error.

    Can I recover selectable text from the images?

    No. This tool renders static page images; it does not perform OCR. Interactive PDF content, complex fonts, colors and some unusual PDF features may not render exactly like a desktop PDF viewer.

    What are the rendering limits?

    PDF files up to 50 MB and 150 pages are accepted. Each rendered page must stay within 16 million pixels and 8192 pixels per side. Results are capped at 256 MB. Choose 1× or a smaller document if the limit is reached. Cancel stops further rendering and retains completed pages.
