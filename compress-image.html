    GOOD TO KNOW

    A few clear answers.

    Which formats can I compress?

    JPG, PNG, and WebP. Automatic output keeps JPG as JPG and WebP as WebP; PNG becomes WebP, which supports transparency and often makes a smaller file. You can choose another output format.

    Is compression lossless?

    JPG and the default WebP output use lossy quality settings. PNG output uses lossless encoding, but resizing still changes pixels. At 100% dimensions, PNG re-encoding is not guaranteed to reduce file size.

    Will transparency be preserved?

    PNG and WebP outputs preserve transparency. Choosing JPG fills transparent areas with white. An explicit notice appears when JPG is selected.

    Can I set an exact number of kilobytes?

    No. The quality percentage is an encoding preference, not a target file size. Results depend on image content, dimensions, browser, and format. Compare the resulting byte counts before downloading.

    What if the compressed file is larger?

    The result shows the actual increase and offers a Keep original link. This downloads the unchanged input, including its original metadata. The tool does not replace your files or claim savings where there are none.

    Is batch compression private and unlimited?

    All processing is local, with no signup or artificial size/count caps. Available memory and browser capabilities still apply. Animation becomes a first frame, metadata is not copied into converted outputs, and huge ZIPs may need smaller batches.
