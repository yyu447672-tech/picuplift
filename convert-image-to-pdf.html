    GOOD TO KNOW

    A few clear answers.

    Are my pictures uploaded?

    Files stay in your browser and are never uploaded. Bundled local scripts do the work. Google Analytics measures visits and fixed interaction events; file names and file contents are not included in the tool events.

    Can I merge several pictures?

    Yes. Each JPG or PNG becomes a separate page in one PDF, in selection order. Clear the list to start a new order. If an image is invalid, the other images can still produce a PDF.

    What page size and quality are used?

    Each image is decoded locally and embedded as PNG pixels in an A4 page, with a 24-point margin and automatic portrait or landscape orientation. No extra JPG quality setting is applied. The PDF can be larger than the source images.

    Can I use this offline?

    The image-to-PDF page works from the complete downloaded folder in a current desktop Chrome or Edge. Keep the assets folder. PDF-to-image separately requires an HTTP(S) page.

    What are the limits?

    Up to 150 images, 50 MB per input file and 16 million pixels per image; PDF results are capped at 256 MB. Your device can run out of memory below those limits. Use smaller batches.
