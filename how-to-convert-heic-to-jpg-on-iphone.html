Convert HEIC to JPG on iPhone Without an App

You can convert HEIC to JPG on an iPhone without installing any app: copy the photo in Photos and paste it into a folder in the Files app, and iOS saves the copy as JPG. Or long-press the file in Files and choose Quick Actions, then Convert Image. The original HEIC stays untouched in your library.

Method 1: Copy in Photos, then paste into Files

Start with one photo so you can check the result before converting a larger selection. Open Photos, select your picture, tap Share, and choose Copy Photos. Open Files, go inside a writable folder, touch and hold an empty area, then tap Paste. Use a new folder if the current one is crowded or the empty area is difficult to find. Your library original is not replaced by copying it.

Inspect the pasted item before sending it to a form or another person. The pasted copy is a JPG (IMG_xxxx.JPG); the original HEIC stays untouched in your library. In Files, touch and hold the new item and open Get Info to confirm the kind and extension before sending it on.

Method 2: Choose JPEG with Files Quick Actions

If the HEIC file is already in Files, touch and hold it and look for Quick Actions → Convert Image. Choose JPEG, then Original for the dimensions. A converted copy appears alongside the source. JPG and JPEG are names for the same format, so either extension is fine when a service asks for a JPG. Choosing Original preserves the pixel dimensions; it does not make lossy JPEG encoding lossless.

If the picture exists only in Photos, first use Share → Save to Files so there is a file to work on. The menu varies by iOS version, file provider, and item type; if Convert Image is missing, try a downloaded local copy in On My iPhone, check for an iOS update, or use the Shortcuts method below. Do not rename .heic to .jpg: changing the label alone does not change the encoded image.

Method 3: Try Most Compatible when sharing

In Photos, open the image, tap Share, and open Options before choosing the destination. If your iOS version offers a Format section, select Most Compatible, then share or save the result. Apple describes this option as allowing files to convert to JPEG or MOV. It is a compatibility preference rather than a promise that every destination receives a JPEG, so verify the received or saved file.

This is convenient when you are already sending a photo, but it is not the same setting as Camera → Formats. The sharing option affects that export, while the Camera setting changes future captures. If the receiving site rejects the file or Files still identifies it as HEIC, use Convert Image or a shortcut that explicitly outputs JPEG. You do not need to delete the original to make a compatible copy.

Method 4: Convert a batch with Shortcuts

Open Apple’s Shortcuts app and create a new shortcut. Add Select Photos, enable Select Multiple, then add Convert Image and set its output to JPEG. Finish with Save File so you choose where the converted copies go. Run it, select a small test batch, and check the saved images. This builds a repeatable workflow using Apple’s own app rather than an unfamiliar third-party converter. If Shortcuts was removed from your phone, you will need to restore it first.

Use the action’s quality control to suit the destination and save to a clearly named folder. Batch capacity depends on available memory, image dimensions, and other activity on your phone; there is no useful universal photo count. Start with a few pictures and split a large job if it becomes slow. Open several outputs and confirm that their format, orientation, and detail are right before sending the whole folder.

Save future camera photos as JPG

For future photos, open Settings → Camera → Formats and choose Most Compatible. Standard new photos then use JPEG instead of the space-saving HEIF format. Existing HEIC photos do not change, so you still need one of the four methods above for your library. Some special capture modes have their own format requirements; check those separately if you use them.

The cost is storage. JPEG photos can take roughly twice the space of HEIC at comparable visible quality, although the ratio varies with the scene and camera settings. Keep High Efficiency if saving storage matters more and create JPG copies only when another service needs them. Keep the HEIC originals as your editing source rather than repeatedly converting a JPG copy into another JPG.

FAQ

Will converting reduce quality?

JPEG is lossy, so some information can be lost during conversion. Keep the HEIC original and check a high-quality JPG copy before sharing.

Does the original HEIC stay in Photos?

Yes, copying or exporting creates a separate file without replacing your library original. Avoid deleting it until you have checked and backed up the result.

What if Convert Image is missing?

Try a local downloaded copy in Files, or use a Shortcuts workflow with Convert Image set to JPEG. Check the output format in Get Info before sending the file on.

How many photos can I convert at once?

The practical limit depends on device memory and photo dimensions. Start with a small batch in Shortcuts or PicUplift and split larger jobs if the device slows down.

Do these iPhone methods work on Android?

No. Photos, Files Quick Actions, and Apple Shortcuts are Apple workflows. Android users can try the browser converter with compatible local files instead.
