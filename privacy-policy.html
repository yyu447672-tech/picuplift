PICUPLIFT · PRIVACY

Privacy Policy

Effective date: November 7, 2026.

The short version: PicUplift does not collect your images. Every file you convert, compress, or turn into a PDF is processed in your browser, on your own device, and is never uploaded to a server. The website uses Google Analytics and Microsoft Clarity to measure visits and interactions only. The Chrome extension makes no network requests at all and includes no analytics, advertising, or tracking.

1. The PicUplift website

The website at picuplift.com is a set of free image tools that run entirely in your browser. Your photos are decoded, converted, and compressed locally with WebAssembly. Nothing you select or drop into a tool is sent anywhere: no file bytes, no file names, no file sizes, and no converted outputs leave your device.

The website uses Google Analytics (measurement ID G-41GRYMECDD) to measure visits and interactions, such as page views, scrolling, and clicks. Analytics does not receive your images or file details. It also does not receive advertising identifiers: Google signals and ad personalization signals are disabled. Microsoft Clarity also records how visitors use the page (clicks, scrolling, and page interaction) to help improve the site. It does not receive your images or file details.

Because the site is static, you can download the complete website folder and use the tools offline. Converted outputs do not copy camera metadata from originals, and your original files are never modified.

2. The PicUplift Chrome extension

This section applies to "PicUplift — Local Image Tools", version 1.0.0.

The extension processes only files you choose or drop into its side panel or optional tab workspace. File bytes, names, and converted outputs remain in that workspace's memory during use. The extension does not collect, transmit, sell, or persist these files or their contents. Clearing or unloading the workspace releases its file references; Chrome manages the underlying memory. Opening a separate tab workspace does not copy any existing files or results.

The extension bundles its conversion libraries and example images locally. It makes no network requests and includes no analytics, telemetry, or advertising. It does not collect browsing history, identifiers, or usage events. Its only permission is sidePanel, needed to show its local tools in Chrome's side panel. It requests no host, tabs, or browsing-data permissions and does not read the content of other tabs or websites.

When you choose Download, Keep original, or Download ZIP, Chrome saves a file through its normal download behavior. Saved downloads remain in the location managed by Chrome. Clearing the workspace does not delete your original files or saved downloads. Original files are never modified by conversion. Converted outputs do not copy original camera metadata; Keep original saves the unchanged input, including its metadata.

The English/Chinese language choice is represented in the local workspace URL. The extension does not use cookies, local storage, browser storage APIs, or a remote account. It does not restore files or conversion results after a page is refreshed or closed.

4. Changes to this policy

If PicUplift's data practices change, this page will be updated and the effective date above will change. Reassess this policy before publishing changes to the extension's data practices.

PICUPLIFT · 隐私

隐私政策

生效日期：2026 年 11 月 7 日。

一句话版本：PicUplift 不收集你的图片。你转换、压缩或转成 PDF 的每一个文件，都在你自己的浏览器里处理，从不上传到服务器。网站只用 Google Analytics 和 Microsoft Clarity 统计访问和互动。Chrome 扩展完全不联网，不含任何分析、广告或追踪。

1. PicUplift 网站

picuplift.com 是一套免费图片工具，全部在浏览器里运行。你的照片通过 WebAssembly 在本地解码、转换和压缩。你在工具里选择或拖入的任何内容都不会发出去：文件内容、文件名、文件大小、转换结果都不会离开你的设备。

网站使用 Google Analytics（衡量 ID G-41GRYMECDD）统计访问和互动，例如页面浏览、滚动和点击。分析服务收不到你的图片或文件信息，也收不到广告标识符：Google 信号和广告个性化信号均已关闭。Microsoft Clarity 也会记录访客如何使用页面（点击、滚动和页面互动），用于改进网站。它收不到你的图片或文件信息。

本站是纯静态网站，你可以下载完整网站文件夹离线使用。转换结果不复制原图的相机元数据，原文件从不被修改。

2. PicUplift Chrome 扩展

本节适用于“PicUplift — Local Image Tools”1.0.0 版。

扩展只处理你自己选择或拖入侧边栏（或可选标签页工作区）的文件。文件内容、文件名和转换结果仅在使用期间保留在该工作区的内存中。扩展不收集、不传输、不出售、不保存这些文件及其内容。清空或卸载工作区会释放文件引用，内存由 Chrome 管理。打开新的标签页工作区不会复制已有文件或结果。

扩展自带转换库和示例图片。不发起任何网络请求，不含分析、遥测或广告。不收集浏览记录、标识符或使用事件。唯一权限是 sidePanel，用于在 Chrome 侧边栏显示本地工具。不请求主机、标签页或浏览数据权限，不读取其他标签页或网站的内容。

选择下载、保留原图或下载 ZIP 时，Chrome 按正常下载行为保存文件。已保存的下载文件保留在 Chrome 管理的位置。清空工作区不会删除原文件或已保存的下载文件。转换从不修改原文件。转换结果不复制原图的相机元数据；保留原图保存的是未经改动的输入，包括其元数据。

中英文切换体现在本地工作区的网址中。扩展不使用 Cookie、本地存储、浏览器存储 API 或远程账号。页面刷新或关闭后，不恢复文件或转换结果。
