    GOOD TO KNOW

    A few clear answers.

    Will the PNG keep a transparent background?

    Yes. The image is drawn onto a transparent canvas and exported as PNG. Transparent pixels remain transparent. The result is checked for a valid PNG output type.

    Why is there a size slider instead of a quality slider?

    PNG uses lossless encoding, so the browser’s JPG/WebP quality setting does not apply. The size slider changes width and height and starts at 100%.

    Why can the PNG file be larger?

    WebP can store images very efficiently. A PNG may be larger even when it looks the same. File-size comparisons show the actual result; no savings are promised.

    What happens to animated WebP?

    Only the first frame is exported. The result row is marked as a static output. This tool does not preserve animation, frame timing, or sound.

    Are there limits or uploads?

    There are no uploads, signups, or artificial conversion limits. Processing is local and sequential. Your browser, memory, and ZIP format still have practical capacity limits. We use Google Analytics to measure visits and interactions (such as page views, scrolling, and clicks). Images are always processed locally and are never uploaded.

    Can I use the results commercially?

    The tool does not change who owns the image. You remain responsible for having permission to use your input files. Converted PNGs do not include the original camera metadata.
