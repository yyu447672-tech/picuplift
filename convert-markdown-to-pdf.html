    GOOD TO KNOW

    A few clear answers.

    Is my Markdown uploaded?

    Files stay in your browser and are never uploaded. Bundled local scripts do the work. Google Analytics measures visits and fixed interaction events; file names and file contents are not included in the tool events.

    Is the PDF text searchable or selectable?

    No. Each A4 page is drawn with local system fonts into an image, then embedded in the PDF. The PDF contains page images rather than a searchable text layer. This supports Chinese without downloading fonts.

    Which Markdown features are supported?

    Headings, paragraphs, bullet and numbered lists (shown as bullets), code blocks, quotes and simple pipe tables are supported. Basic emphasis markers are simplified to plain text; table rows use plain text separators. This is not a full publishing or GitHub Markdown engine.

    Are HTML, images or linked resources loaded?

    No. HTML is displayed as plain text. Links become text and images are omitted with a note. No Markdown-provided resource is fetched, and no script is executed. The tool is designed for plain text notes.

    What limits and offline support apply?

    Keep Markdown under 250,000 characters and the output under 150 pages and 256 MB. Very long documents can exceed device memory. The complete downloaded folder works in current desktop Chrome or Edge without a server; fonts depend on your device.
